Cypher Reference Guide

Supported Clauses

  • MATCH - Pattern matching
  • OPTIONAL MATCH - Optional matching
  • CREATE - Create nodes/edges
  • MERGE - Match or create
  • SET - Update properties/labels
  • REMOVE - Remove properties/labels
  • DELETE - Delete nodes/edges
  • WITH - Pipe intermediate results
  • RETURN - Output results
  • ORDER BY - Sort results (ASC/DESC)
  • SKIP / LIMIT - Pagination
  • UNWIND - Expand lists
  • CALL - Run subqueries
  • CREATE INDEX / DROP INDEX

Functions

  • Math: abs(), round(), ceil(), floor(), sqrt(), power()
  • String: tolower(), toupper(), substring()
  • Aggregates: COUNT(), MIN(), MAX(), COLLECT()
  • Misc: coalesce(), id(), rand()

Operators

  • Comparison: =, <>, <, >, <=, >=
  • Boolean: AND, OR, NOT
  • Null check: IS NULL, IS NOT NULL
  • String: STARTS WITH, ENDS WITH, CONTAINS
  • List: IN

Example Queries

  • CREATE (n:Person {name: 'Alice'}) RETURN n
  • MATCH (n) RETURN n.name, id(n)
  • MATCH (a)-[r]->(b) RETURN a, r, b
  • UNWIND [1, 2, 3] AS x RETURN x
